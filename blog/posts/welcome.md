# Welcome to My Blog

This is a sample blog post to demonstrate how the blog system works. You can write your posts in Markdown and they'll be automatically rendered on the website.

## Features

The blog supports all standard Markdown features:

- **Bold text** and *italic text*
- [Links](https://govgandhi.github.io)
- Lists (like this one)
- Code blocks with syntax highlighting

### Code Example

Here's some Python code:

```python
import networkx as nx

# Create a simple graph
G = nx.Graph()
G.add_edges_from([(1, 2), (2, 3), (3, 1)])

# Calculate centrality
centrality = nx.degree_centrality(G)
print(centrality)
```

### Math and Equations

You can include inline math or describe equations in text. For LaTeX support, you could add MathJax or KaTeX.

## Getting Started

To publish a new post:

1. Write your post in Markdown (e.g., in Obsidian)
2. Run the publish script with the path to your markdown file
3. The post will automatically appear on your blog
